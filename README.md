# 우주 별빛 구조대

초등학교 1학년을 위한 한글 키보드 연습 웹앱입니다.

- 로그인, 서버, 개인정보 수집 없이 실행
- 연습, 세 줄을 섞은 20문항 점검, 오답 복습, 단어 행성
- 클릭 또는 Enter로 다음 문제 이동
- 점검 첫 입력 정확도로 평가, 새로 시작하면 기록 초기화

## GitHub Pages 배포
1. 이 폴더의 index.html을 저장소 최상위에 올립니다.
2. 저장소 Settings → Pages → Deploy from a branch를 선택합니다.
3. main 브랜치, /(root)를 선택하고 Save를 누릅니다.
4. Pages에 표시되는 사이트 주소를 학생에게 전달합니다.

인터넷 없이 사용하려면 index.html을 내려받아 Edge 또는 Chrome에서 엽니다.
